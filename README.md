# Procesamiento de Datos con Apache

Repositorio correspondiente a la Tarea 3 de procesamiento de datos en tiempo real y por lotes utilizando Apache Kafka y PySpark.

## Archivos del proyecto
* `batch_siniestros.py`: Procesamiento por lotes de siniestros.
* `kafka_traffic_producer.py`: Productor de eventos de tráfico en Kafka.
* `spark_streaming_consumer.py`: Consumidor de Streaming con PySpark.
